# tania-mason-site

**Personal site of Tania Mason — Payer Delivery Governance & Governed AI.**

**Live:** https://framework-optimization-lab.github.io/tania-mason-site/

Fully self-contained static site: one hand-written HTML file, locally served fonts
(Libre Baskerville, IBM Plex Sans, IBM Plex Mono), and the TM monogram. No frameworks,
no build step, no external requests, no third-party hosting dependencies. Open
`index.html` in any browser or host it as static files anywhere.

| | |
|---|---|
| `index.html` | The entire site — markup, styles, and the scroll-reveal script |
| `fonts/` + `fonts.css` | Locally hosted font faces (latin subsets) |
| `logo-badge.png` | TM monogram |

Design: warm archival paper against navy ink, brass accents — an editorial layout
with an engraved-grid hero, specimen cards, a career-spine timeline, and a
credentials ledger.
